# Retired SDDM integration

The SDDM/Astronaut preview integration was removed in source version 2.0.0.
Use the [native login screen editor and greetd session](LOGIN_SCREEN.md).
Historical validation records remain in `SDDM_*_TEST_RESULTS.md` and refer only
to the versions they name. Their setup instructions do not apply to version 2.0.
The application does not delete the system SDDM package or historical user data.
